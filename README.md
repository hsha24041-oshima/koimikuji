恋みくじアプリ（最強版）
ボタンをクリックするだけで、今日の恋愛運を占うことができるシンプルなウェブアプリケーションです。

特徴
シンプル操作: 「おみくじを引く」ボタンを押すだけで即座に結果が表示されます。

おみくじの種類: 大吉、中吉、小吉、凶の4つの運勢がランダムで表示されます。

レスポンシブデザイン: 赤を基調としたおみくじらしいデザインを採用しています。

構成ファイル
プロジェクトは以下の3つのファイルで構成されています。

index.html - アプリの構造（HTML）

style.css - デザイン・レイアウト（CSS）

script.js - おみくじの抽選ロジック（JavaScript）

使い方
リポジトリ内のすべてのファイルを同じフォルダにダウンロードします。

index.html をブラウザ（Google Chrome, Microsoft Edge, Safariなど）で開きます。

画面中央の「おみくじを引く」ボタンをクリックして運勢を確認してください。
